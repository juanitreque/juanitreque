# juanitreque

I create, test and share useful tools, automations and practical projects.

## Current project

[WhatsApp Without Contact](https://github.com/juanitreque/whatsapp-sin-contacto-shortcut) is an Apple Shortcut reconstruction that prepares WhatsApp chats from phone numbers without saving a contact, with recipient confirmation before opening WhatsApp.

[Explore version 3.0 beta 5](https://github.com/juanitreque/whatsapp-sin-contacto-shortcut/releases/tag/3.0-beta.5) for installation, validation notes, known limitations and credits. It is a pre-release; opening a real WhatsApp chat was not performed during validation.

I share what I build, what I learn and what still needs testing.
